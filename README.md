# Fitness Hub — النسخة المتكاملة الأولية 1.0

تطبيق ويب شخصي باللغة العربية واتجاه RTL لإدارة الملف الشخصي، تقديرات الاحتياج الغذائي، سجل الطعام، التمارين المنزلية/الجيم، القياسات، إدخال تقارير InBody يدويًا، الملاحظات، النسخ الاحتياطي، والمظهر الفاتح/الداكن.

## المتطلبات
- Node.js 20.19+ أو 22.12+
- اتصال بالإنترنت لأول مرة لتنزيل الحزم (`npm install`). لا توجد اشتراكات أو مفاتيح API مطلوبة. مكتبة OCR مجانية، وقد تتطلب تنزيل ملفات تشغيل/لغة عبر الإنترنت عند أول استخدام.

## التشغيل
1. فك ضغط ملف ZIP.
2. افتح Terminal / PowerShell داخل مجلد `fitness-hub`.
3. نفّذ بالترتيب:
   ```bash
   npm install
   npm run typecheck
   npm run build
   npm run dev
   ```
4. افتح عنوان localhost الذي يظهر في الطرفية.

## الميزات المتاحة
- واجهة عربية RTL متجاوبة للكمبيوتر والموبايل، ووضع فاتح/داكن.
- ملف شخصي وحسابات تقديرية لـ BMR وTDEE والسعرات والبروتين والكربوهيدرات والدهون.
- سجل الطعام بقاعدة صغيرة من الأطعمة الشائعة، وكميات محسوبة لكل 100 جم، وإضافة أطعمة مخصصة.
- تسجيل الوجبات بحسب التاريخ والوجبة، وعرض مجموع اليوم.
- تسجيل تمارين البيت والجيم ومدتها وملاحظاتها.
- تسجيل الوزن ومحيط الخصر ونسبة الدهون والكتلة العضلية، ومقارنة أول وآخر وزن.
- إدخال قيم تقرير InBody يدويًا وتخزين أكثر من تقرير، مع OCR تجريبي للصور باللغة الإنجليزية عبر Tesseract.js؛ راجع كل قيمة مقترحة يدويًا قبل الحفظ.
- دفتر ملاحظات وتصنيفات.
- تصدير واستيراد نسخة احتياطية بصيغة JSON، مع تأكيد قبل الاستبدال أو المسح.
- Service worker مبدئي للتخزين المؤقت لملفات التطبيق؛ جرّب وضع عدم الاتصال بعد فتح التطبيق مرة أثناء الاتصال.
- التخزين محلي في المتصفح عبر localStorage؛ لا يوجد حساب أو خادم أو مزامنة بين الأجهزة.

## حدود مهمة معروفة
- هذه نسخة MVP وليست منتجًا طبيًا معتمدًا. حسابات الطاقة تقريبية باستخدام Mifflin–St Jeor ومعاملات نشاط شائعة، ولا تناسب كل الحالات الطبية. راجع مختصًا عند وجود حالة صحية أو أعراض أو تغير وزن غير مقصود.
- قاعدة الطعام المبدئية صغيرة وقيمها تقريبية. استخدم ملصق المنتج أو مصدرًا غذائيًا موثوقًا عند الحاجة إلى دقة أعلى.
- OCR تجريبي وليس موثوقًا بما يكفي للاعتماد التلقائي؛ قد يحتاج تنزيل ملفات اللغة أول مرة، والقيم المقترحة يجب مراجعتها يدويًا. لا يوجد ذكاء اصطناعي خارجي أو خطة غذائية مولدة تلقائيًا.
- توجد رسوم بيانية للوزن والخصر ونسبة الدهون والكتلة العضلية عند توفر قياسين على الأقل.
- التخزين محلي داخل المتصفح، وقد يُمسح عند مسح بيانات المتصفح. صدّر نسخة احتياطية بانتظام. لا تنتقل البيانات تلقائيًا بين الكمبيوتر والهاتف.
- ملفات التطبيق الأساسية يمكن أن تُخزّن مؤقتًا بعد فتحه، لكن لا نضمن كل الوظائف في وضع عدم الاتصال على كل المتصفحات. تثبيت PWA يحتاج تقديمه عبر localhost أو HTTPS.
- خط Cairo يُحمّل من Google Fonts عند توفر الإنترنت؛ الواجهة تستخدم خطوطًا احتياطية إذا لم يتوفر.

## الاختبار
شغّل `npm run typecheck` ثم `npm run build`. لا تعتبر النسخة مختبرة حتى تنجح هذه الأوامر وتجرب الصفحات يدويًا في المتصفح. لم يُرفق أي بيانات صحية افتراضية أو سجلات مزيفة.

## إضافات النسخة المحدّثة

- حفظ الأطعمة المخصصة في قائمة الطعام وإضافتها للسجل، مع إمكانية اختيارها كبدائل داخل خطة الوجبات.
- مقارنة السعرات المسجلة بالهدف اليومي التقديري.
- جدول تمارين قابل لتحديد أيامه ووقته، وتذكيرات للوجبات والتمرين عبر إشعارات المتصفح.
- رفع فيديوهات التمارين ومشاهدتها لاحقًا؛ تُحفظ الفيديوهات في IndexedDB على الجهاز نفسه ولا تدخل في ملف النسخ الاحتياطي JSON.
- حقول إضافية لتقارير InBody، ومقارنة التغيرات، وتعديل التقارير السابقة، وتجربة OCR بالعربية والإنجليزية.
- شروحات نصية لاتجاهات الرسوم البيانية.

## حدود مهمة

- لا يتصل التطبيق بخدمة ذكاء اصطناعي خارجية؛ تفسير تقارير InBody وصف رقمي مبسط وليس تشخيصًا طبيًا.
- OCR بالعربية والإنجليزية تجريبي وقد يخطئ، خصوصًا في الصور غير الواضحة أو اختلاف تصميم التقرير. راجع الأرقام يدويًا قبل الحفظ.
- تذكيرات المتصفح تعمل أثناء بقاء الموقع مفتوحًا؛ لا تضمن تذكيرًا عندما يكون الموقع مغلقًا بالكامل.
- بيانات التغذية والتمارين تقديرية، والخطة قابلة للتعديل ولا تغني عن مختص عند وجود حالة صحية.


## تحديث v5 — إصلاح البحث عن الطعام وتحسين البدائل

- عند البحث عن اسم طعام مطابق لقائمة الأطعمة، يتم ربط الاسم المختار بنتيجة البحث بدل الاحتفاظ بأول عنصر افتراضي.
- يمكن كتابة اسم طعام غير موجود في البحث، وإدخال قيمه الغذائية في النموذج نفسه؛ يحفظه التطبيق في قائمة الأطعمة المخصصة ويضيفه لسجل الوجبة المختارة.
- معاينة السعرات والمغذيات للطعام الجديد تعتمد على الكمية المرجعية التي أدخلها المستخدم.
- بدائل الوجبات المخصصة تعرض كمية تقريبية مكافئة في السعرات للطعام الأصلي، بدل استخدام نفس الوزن دائمًا.
- تنبيه السعرات يوضح المتبقي للوصول إلى الهدف أو مقدار التجاوز، بدل اعتبار كل القيم ضمن هامش 10% متقاربة.

ملاحظة: قيم التغذية يضيفها المستخدم ويجب مراجعتها من ملصق موثوق؛ تنبيهات المتصفح تعمل أثناء بقاء الموقع مفتوحًا، وقراءة صور InBody تجريبية وليست تحليلًا طبيًا أو ذكاءً اصطناعيًا متصلًا بخادم.
